隱私權政策

Privacy Policy

「瑋瑋老師的撒野記事錄」重視使用者的個人資料與隱私。本政策說明本網站及活動報名系統如何蒐集、使用、保存與保護相關資料。

最後更新日期：2026 年 8 月 10 日

一、蒐集的資料

當您使用活動報名功能時，我們可能蒐集：

  • 聯絡人姓名
  • 電話號碼
  • E-mail
  • LINE ID
  • 活動參加者姓名與生日
  • 報名活動、報名人數與報名時間

二、資料使用目的

上述資料僅用於與活動相關之必要用途，包括：

  • 處理活動報名與名額管理
  • 寄送報名確認信
  • 提供匯款、集合、行前提醒或活動異動資訊
  • 就報名內容與參加者聯絡
  • 處理取消、修改或其他報名相關需求

三、Google Gmail API 的使用

本系統使用 Google Gmail API，由專用 Gmail 帳號寄送活動報名確認信及活動相關通知。

本系統所要求的 Google OAuth 權限限於：

  • https://www.googleapis.com/auth/gmail.send — 代表授權帳號寄送電子郵件。

本系統不要求 Gmail 收件匣讀取、信件修改或刪除權限，也不使用 Gmail API 讀取使用者的郵件內容。

Google OAuth 憑證與 refresh token 僅保存在伺服器端受保護的環境中，不會放置於公開網站程式碼或 GitHub Pages 前端。

四、Google 使用者資料的使用與分享

透過 Google API 取得的授權資料僅用於執行本系統的自動寄信功能。

  • 不出售 Google 使用者資料。
  • 不將 Google 使用者資料提供給廣告商。
  • 不使用 Google 使用者資料進行廣告或行銷剖析。
  • 除提供必要的系統基礎設施與法令要求外，不會將 Google 使用者資料提供予無關第三方。

五、資料保存與安全

活動報名資料儲存在受存取控制保護的後端資料庫中。管理功能僅開放予授權管理員使用。

我們會採取合理的技術與管理措施降低未經授權存取、修改、洩漏或遺失資料的風險。

六、資料刪除與更正

如需查詢、更正或要求刪除您提供的活動報名資料，請透過下方聯絡方式與我們聯繫。我們會在合理範圍內協助處理。

七、第三方服務

本網站及報名系統可能使用第三方基礎設施服務，例如 GitHub Pages、Supabase 與 Google Gmail API。這些服務各自有其隱私與安全政策。

八、政策更新

本政策可能因服務調整、法律要求或技術變更而更新。最新版將公布於本頁面。
